Leaderboards

Author boards, run the recovery operations on a cycle, and decide what counts as a believable score.

Adding a leaderboard is an INSERT, not a release. Boards are data, so a seasonal event needs no migration, no deploy and no client update.
Nothing here accepts a score. Ranking is projected server-side from results the server itself graded — there is no route by which a client can state one, which is why a modified build cannot author its own rank.
Boards stay invisible to players until Leaderboards:Enabled is on. Every player-facing read answers 409 LB_DISABLED while the switch is off. This console is deliberately not gated by it, so boards can be prepared before the feature opens.
