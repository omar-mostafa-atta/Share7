Upload a question sheet

Select a lesson on the Tree tab first. One worksheet, 4 columns — question, correct answer, wrong, wrong. .xlsx only, ≤ 10 MB, ≤ 5000 rows.

langId is required — a lesson is shared across languages, and each language keeps its own question set and version.
Type questions by hand

Same tables, same versioning as the sheet above — typed instead of uploaded. The first choice is the correct one. Select a lesson on the Tree tab first.

Both modes publish a new version — a set is never edited in place, so every client caching this lesson re-downloads it. Answers must differ from each other, and case counts (Fe and FE are two different answers).
Upload a recovery question sheet

The lesson's secondary pool. Same sheet format as the main questions. Select a lesson on the Tree tab first.

The two pools are versioned independently: uploading here bumps the recovery version only and never touches the lesson's main question set.
